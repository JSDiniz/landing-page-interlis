# 🧬 Interlis - Gestão Laboratorial Inteligente

O **Interlis** é uma plataforma de gestão laboratorial (LIS) de alta performance, projetada para otimizar o fluxo de trabalho em análises clínicas. O foco do sistema é proporcionar fluidez operacional, permitindo que a tecnologia cuide da organização enquanto os analistas focam na precisão técnica.

## 🚀 Funcionalidades Principais

  * **Gestão de Pacientes e Exames:** Cadastro organizado e rastreio completo de resultados.
  * **Interfaceamento Contínuo:** Integração nativa com equipamentos de grandes marcas como Roche, Mindray, Radiometer e Human.
  * **Controle de Acesso:** Níveis de autorização granulares para segurança de dados.
  * **Gestão de Materiais:** Controle de estoque de insumos e reporte de custos.
  * **Acesso Multiplataforma:** Interface responsiva otimizada para Desktop, Tablets e dispositivos Mobile.
  * **Resultados Online:** Portal seguro para entrega de resultados aos pacientes.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com o que há de mais moderno no ecossistema React para garantir performance e uma experiência de usuário (UX) fluida:

  * **Framework:** [Next.js 13.5](https://nextjs.org/) (App Router)
  * **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
  * **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
  * **Animações:** [Framer Motion](https://www.framer.com/motion/)
  * **Componentes de UI:** [Radix UI](https://www.radix-ui.com/) & [Shadcn/UI](https://ui.shadcn.com/)
  * **Ícones:** [Lucide React](https://lucide.dev/)

## 📂 Estrutura de Componentes

O projeto utiliza uma arquitetura baseada em seções modulares:

  * `Hero.tsx`: Seção principal com chamada para ação (CTA) e visualização do dashboard.
  * `Advantages.tsx`: Grade de benefícios e diferenciais do sistema.
  * `Integration.tsx`: Demonstração visual do ecossistema de aparelhos suportados.
  * `Fluidity.tsx` / `Features.tsx`: Seções detalhadas sobre a eficiência operacional e escalabilidade.
  * `Platform.tsx`: Demonstração da responsividade em múltiplos dispositivos.
  * `Testimonials.tsx`: Prova social com depoimentos de diretores médicos e gestores.

## 🔧 Instalação e Execução

Para rodar o projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/seu-usuario/interlis.git
    ```

2.  **Instale as dependências:**

    ```bash
    npm install
    # ou
    yarn install
    ```

3.  **Inicie o servidor de desenvolvimento:**

    ```bash
    npm run dev
    # ou
    yarn dev
    ```

4.  **Acesse no navegador:**
    Abra [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000).

## 📝 Scripts Disponíveis

  * `npm run dev`: Inicia o ambiente de desenvolvimento.
  * `npm run build`: Cria a versão de produção otimizada.
  * `npm run start`: Inicia o servidor em modo de produção.
  * `npm run lint`: Executa a verificação de erros no código.
